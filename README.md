# website

The landing page of [Action Platform](https://github.com/actionplatform/action-platform) — Next.js, statically exported, published on GitHub Pages from `master`.

```bash
npm install
npm run dev      # http://localhost:3100
npm run build    # out/
```

Same tokens, components and tone as the web app (`apps/web`): black, white and grey, no gradients. The screens in it are built from the platform's own components, not screenshots.
